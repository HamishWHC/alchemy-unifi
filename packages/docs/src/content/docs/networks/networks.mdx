title: Networks

A [`Network`](/reference/network/) is a VLAN. `management` picks who routes it: `"GATEWAY"` (the usual kind, with DHCP, a zone and internet access), `"SWITCH"` (a layer-3 switch) or `"UNMANAGED"` (carried, not routed).

## Create a gateway network

```ts
// src/networks.ts
import * as UnifiNetwork from "@alchemy-unifi/network";
import * as Effect from "effect/Effect";

export const networks = Effect.gen(function* () {
	const lab = yield* UnifiNetwork.Network("lab", {
		management: "GATEWAY",
		name: "Lab",
		vlanId: 50,
		enabled: true,
		cellularBackupEnabled: false,
		internetAccessEnabled: true,
		isolationEnabled: false,
		zone: UnifiNetwork.FirewallZone.INTERNAL,
		ipv4Configuration: { autoScaleEnabled: false, hostIpAddress: "192.168.50.1", prefixLength: 24 },
	});
	return { lab: lab.networkId };
});
```

`zone` is required on every Network 10.6 site. Changing `management` or `site` replaces the network.

## Hand out addresses with DHCP

```ts
// src/networks.ts
import * as UnifiNetwork from "@alchemy-unifi/network";
import * as Effect from "effect/Effect";

export const networks = Effect.gen(function* () {
	yield* UnifiNetwork.Network("lab", {
		management: "GATEWAY",
		name: "Lab",
		vlanId: 50,
		enabled: true,
		cellularBackupEnabled: false,
		internetAccessEnabled: true,
		isolationEnabled: false,
		zone: UnifiNetwork.FirewallZone.INTERNAL,
		ipv4Configuration: {
			autoScaleEnabled: false,
			hostIpAddress: "192.168.50.1",
			prefixLength: 24,
			dhcpConfiguration: {
				mode: "SERVER",
				ipAddressRange: { start: "192.168.50.100", stop: "192.168.50.250" },
				leaseTimeSeconds: 86400,
				pingConflictDetectionEnabled: true,
			},
		},
	});
});
```

## Isolate a network

`isolationEnabled: true` blocks the network from every internal zone, its own included, and `internetAccessEnabled: false` blocks it from `External`. Both work through system firewall policies; to let some traffic through, put an allow before them with [Ordering](/firewall/ordering/).

## Carry a VLAN for another router

```ts
// src/networks.ts
import * as UnifiNetwork from "@alchemy-unifi/network";
import * as Effect from "effect/Effect";

export const ispHandoff = UnifiNetwork.Network("isp-handoff", {
	management: "UNMANAGED",
	name: "ISP handoff",
	vlanId: 99,
	enabled: true,
}).pipe(Effect.asVoid);
```

## Manage the default network

Declare a `Network` with `vlanId: 1` and its current settings, and deploy once with `--adopt`. It's never deleted. [Part 2 of the tutorial](/tutorial/part-2/) walks through it.

See the [`Network` reference](/reference/network/) for mDNS, replacement and what the console requires.
